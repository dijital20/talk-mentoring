# Mentoring... or what I've learned so far

This repository contains the slides for my talk on Mentoring.

## Where has this talk been delivered?

- [PyTexas 2026 Conference (Lightning Talk)](https://youtu.be/STGlXoMyhRU?si=wphAlatgKzeraKhR) - April 18 2026 - Austin, TX
- PyTexas Virtual Meetup - June 2nd 2026 - Discord

## How do I navigate the content

Glad you asked! There are 2 versions of the talk:

- The lightning talk - This is formatted for 5 minutes, and only covers "Session 0". This is in the `lightning/` folder.
- The full talk - This is formatted for closer to 30 minutes. This is in the `full/` folder.

All slides are done using [Marp](https://marp.app). When I make changes and they are merged into `main`, a release is created. 
In each release, there are copies of the slides in HTML and PDF format.
